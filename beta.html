כניסת מנהל

🔒 Security Rules ל־Firebase

כאן מעתיקים את ה־Rules, מדביקים ב־Firebase → Firestore Database → Rules ולוחצים Publish. זה נדרש כדי שהרשמה עצמית ושמירת עובדים יעבדו בלי חסימת הרשאות.

🧪 כלי בדיקות מטמון מקומי

הכפתורים מוחקים רק מידע מקומי במכשיר. הם אינם מוחקים עבודות או נתונים מ-Firebase.

נקה מטמון נתונים: IndexedDB, מטמון Firestore ו-Cache Storage. איפוס מלא מוחק בנוסף localStorage ו-sessionStorage ועלול לנתק מהחשבון.

📦 ייצוא, גיבוי, שחזור ותבניות

כלי ניהול מתקדמים: ייצוא אדמין מלא לאקסל, גיבוי מלא, שחזור מלא ותבניות התקנה מוכנות.
