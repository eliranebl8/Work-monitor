לוח מנהל

ניהול עובדים, מחירון, הגדרות מנהל וצפייה בדוחות.

🔐 הכנת Firebase Auth

גרסה זו מחברת התחברות Firebase Auth ומכינה Security Rules: authUid, authEmail ו־users/role. עדיין לא מחליפים Security Rules עד שנבדוק שכל העובדים נכנסים תקין.

שלב בטוח: המערכת ממשיכה לעבוד גם עם ההתחברות הישנה, ובמקביל מכינה נתונים לנעילת Firestore בהמשך.

💳 מעקב תשלומים ומנויים

כאן תראה מי בחר מסלול, כמה הוא אמור לשלם, מתי הוא לחץ לתשלום, ומה סטטוס הבקשה. עד שנחבר סליקה אוטומטית, אפשר לאשר תשלום ידנית, לבטל בקשה או למחוק אותה לגמרי.
